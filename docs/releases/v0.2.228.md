# NanoHarness v0.2.228

## Reliability & Auto-Updates

- Keep background Codegraff (`~/.harness/bin/graff`) auto-updates retrying quietly (`30s -> 2m -> 10m`) on transient failures before falling back to the manual `"Codegraff engine update available"` prompt (#108).
- Harden `graff_update` downloads and atomic swaps with `/usr/bin/curl` retries, immediate file-descriptor closure, explicit `/usr/bin/tar`, `/bin/chmod`, and `/usr/bin/find` paths, direct archive lookup, and pre-swap `graff --version` verification (#108).
- Keep the sidebar app-updater row aligned with Settings by surfacing `"Retry update"` and the failure detail when an app update fails instead of offering a stale restart (#85, #107).

## Editor, Math & Input Fixes

- Render inline `\displaystyle`, `\textstyle`, `\scriptstyle`, and `\scriptscriptstyle` declarations and standalone braced math groups at their scoped TeX sizes and boundary spacing while keeping the original source selectable and copyable (#91, #107).
- Preserve composer drafts, attachments, and clear blocker notices when `Steer` is selected but unavailable instead of silently falling back to `Queue` (#95, #107).
- Read dragged macOS local files eagerly inside `performDragOperation:`, fall back to `public.png`/`public.tiff` pasteboard data when local paths are transient or absent, and report `AccessDenied` separately from missing files (#97, #107).
