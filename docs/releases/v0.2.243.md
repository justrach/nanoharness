# NanoHarness v0.2.243

## Desktop UX and startup fixes

- **Faster cold engine startup reconnect (#204, #220):** Retry every 50 ms during the initial two-second cold-start window (`retryDelayMs`), while keeping 200 ms fast restarts after replacing an older engine process and the existing two-second steady-state backoff thereafter.
- **Legible attachment remove button on hover (#203, #221):** Composite the remove badge hover tint over the opaque composer background (`removeHoverBg`) so hovering over dark thumbnails no longer makes the `×` badge translucent.
- **Reactivate the GitHub pane when clicking its body (#209, #222):** Always register `workspace-host-body` in the painted hit tree before checking pointer presses so clicking empty body area switches focus back from the chat pane while keeping child controls clickable.
- **Hide pagination on single-page GitHub Activity timelines (#208, #223):** Hide the divider and `Previous / Page 1 / Next` footer when a GitHub Activity timeline fits on page 1 with no next page, while keeping pagination on multi-page timelines.

## Worktree privacy

- **Prompt-free default Graff worktree branches (#214, #219):** Generate an opaque, chat-id-derived default name (`worktree-<16hex>`) instead of embedding first-message prompt words in the Git branch ref, while leaving existing worktree reuse and explicit `-w <name>` choices unchanged.
