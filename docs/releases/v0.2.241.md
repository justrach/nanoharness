# NanoHarness v0.2.241

## Typed slash commands

- Show a notice while a typed slash command waits for the agent's command list. Since v0.2.239, a draft that is just a command, such as `/compact`, sent before the list loads is held and goes out as the command once the list arrives. That wait was silent: the command stayed in the composer with no sign it would be sent, which invited typing it again into a draft that already held it. The composer now reads "Loading this agent's commands. /compact goes out as soon as they're in." The notice clears when the command is sent, when the draft changes, and when the chat or agent changes (#211).
