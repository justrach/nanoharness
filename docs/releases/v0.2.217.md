# NanoHarness v0.2.217

## Desktop UI & Split Panes

- **Narrow split-pane tab chips (#74):** Degrades device/folder chips in clean stages down to clickable `16px` glyphs with hover tooltips and verifies shaped `ellipsisText` candidates against `max_w`, preventing bare `"…"` stubs and clipped dropdown chevrons.
- **Split-pane tab column alignment (#74):** Keeps interior and opposite-edge split-pane tabs pixel-aligned over their columns below when collapsed-sidebar or trailing controls squeeze an edge pane below `slot_min`.
- **Zen top tab bar (#74):** Accounts for the `+` button room before triggering `+N` overflow, computes exact label widths without invisible inactive spacers, and renders multi-pane workspace tabs as single-line pills with a compact pane-count badge.
- **Dedicated opaque onboarding screen (#74):** Renders first-run onboarding as a standalone opaque blocking screen instead of a translucent overlay over the live workspace, blocking background input, shortcuts, and WebViews.
- **Blank New tab sidebar navigation (#74):** Opening an unopened sidebar conversation while on a blank New tab (single tab or split pane with no draft, attachments, or dirty editor) replaces that New tab in place instead of abandoning it.
- **Narrow side-panel picker and topbar clearance (#74):** Sizes host surface-picker rows responsively with truncation so narrow panels never clip borders or labels, and reserves full trailing toolbar room so `+` never overlaps `Toggle side panel`.
- **Narrow Markdown tables (#75):** Preserves readable column minimums and scrolls wide tables horizontally inside narrow split panes instead of crushing columns into 1-character vertical stacks.
