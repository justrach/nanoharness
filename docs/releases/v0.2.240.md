# NanoHarness v0.2.240

## Cloud sandboxes and remote control

- Enable remote control and first-action relay admission in memory on headless cloud sandboxes (`HARNESS_SANDBOX_TOKEN_FILE`) without persisting to `harness-prefs.json`, while keeping `LocalOnly` and non-forwardable RPCs blocked so sends to Cloud Computers and Fleet Sandboxes execute immediately instead of sitting at `Waiting for host` (#206).
- Turning **Allow remote control** on (`SetRemoteControl`) now clears parked remote command approvals, drains waiting remote chats immediately, and refreshes Settings → Devices (#206).
- Stamp `relayDeviceId` on relayed `UploadChunk`, `UploadCommit`, and `RelayCommand` calls so approved peer devices are attributed correctly when forwarding attachments (#206).
