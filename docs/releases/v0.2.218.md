# NanoHarness v0.2.218

## Smaller desktop packages

- macOS, Windows, Linux, and Arch packages now build the Rust engine with the size-optimized profile, without removing features. On Apple silicon the engine executable shrank from 25.6 MB to 13.9 MB (46% smaller). This measures the executable, not the entire installer.

## Desktop UI

- Diff views scroll independently and keep file headers visible. Long menus render only the rows in view, and narrow panes handle the available width better (#78).
- Finished agent and engine updates no longer show up in the top-bar activity indicator (#77).
