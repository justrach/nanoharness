# NanoHarness v0.2.242

## Antigravity questions

- Antigravity's questions now open the question picker instead of appearing in its reply as `- [1] …` rows that had to be answered by typing a number. Harness now tells `agy` it can take a question form, and reads the form `agy` sends: one page per question, single or multiple choice, and a typed answer for any question in place of a pick. Verified with `agy` 1.5.14; older CLIs and the legacy `agy_acp_server` keep asking in chat (#215).
