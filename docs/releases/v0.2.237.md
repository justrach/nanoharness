# NanoHarness v0.2.237

## Headless Linux opt-in and Antigravity

- Honor a hand-edited `optedIn` in `{data_dir}/harness-prefs.json` on a Linux host with no desktop: accept string and map forms, keep other fields when a key is the wrong type, and merge a leftover `"enabled"` key instead of overwriting `optedIn` (#187).
- Find `agy` on systemd's minimal PATH (`~/.local/bin` and the usual install dirs), record the Google OAuth URL through a `$BROWSER` shim, and complete login with `agy acp --login` paste-code so a remote host does not wait on `127.0.0.1` (#187).
- Read agy 1.5.17 settings from `$GEMINI_HOME/antigravity-cli/settings.json` as well as the older `antigravity-acp` path; `harness daemon install` captures `ANTIGRAVITY_ACP_EXECUTABLE`, `GEMINI_HOME`, and `GEMINI_API_KEY` (#187).
- Exit cleanly when `HOME` and `HARNESS_DATA_DIR` are both unset, and document the Linux `tar.gz` + `install.sh` install path (#187).

## Remote control default-off and hardening

- Keep device-room host `ControlRpc` off until `remoteControl` is true in prefs, so a compromised edge cannot drive the host (#179).
- Drain the late phone command after opt-in, require device keys, signed updates, and the E2EE flag, and fix Zig compile plus iOS `DeviceCrypto` try (#180).

## Desktop fixes

- Fix a crash when the same slash command is accepted twice: the newest accept replaces the earlier reference, and a draft with invalid references is kept instead of aborting the app (#178, #185).
- Keep a replaced macOS app bundle on disk until no process runs from it, so the Open panel behind the composer paperclip keeps working between an update and the relaunch. Old bundles are removed at a later update check (#173, #183).
- Open the project picker beside the project it changes when a Files or host tab has the focus, in full screen, and after the window is resized (#15, #189).
- Show why an agent update failed: npm's reason instead of its log path, Homebrew's error instead of its wrapper, and the Xcode license only when the installer names it (#125, #184).
- Run agent updates in their own process group with bounded output, so a hung installer or a grandchild holding its pipes can no longer stall an update, and show **Cancel** while an update is installing (#194).
- Typeset `\operatorname*{…}`, `\middle` delimiters and the `gathered` environment instead of falling back to source (#156, #190).

## Quote a reply in a follow-up

- Select text in an assistant reply and choose **Add to chat**: a removable quote chip joins the draft, a click on the chip scrolls back to the passage, and the quote is sent as a blockquote ahead of the message (#152, #191).

## Full-screen Cmd+B

- Toggling the sidebar in full screen no longer stalls at the end of the slide in split panes with long chats: off-screen rows are measured again a few per frame, text breaks into lines once per slide, and a showing hover peek docks in place (#192).

## Security

- Isolate sandbox tokens, authenticate loopback IPC, gate human approvals, and unify relay hops (#182).

## Build

- Pass an `std.Io` to `Ed25519.KeyPair.generate` so `apps/nano` compiles under Zig 0.17 (#186).
