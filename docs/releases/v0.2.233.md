# NanoHarness v0.2.233

## Full-Screen Sidebar Hover Peek & Command Switcher Actions

- Add a browse-style fullscreen left-edge hover sidebar peek (`left_edge_px` dwell, leave grace, `Escape` / outside-click dismissal, and click-to-dock toggle) that overlays the sidebar without reflowing the transcript canvas (#162).
- Add richer `⌘K` Command Switcher session actions: `⌘R` to rename chats, `⇧⌘D` to open a sibling tab in the same project and computer, and `⌘Del` to archive saved chats (#162).
