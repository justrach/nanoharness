# NanoHarness v0.2.221

## Desktop chat

- Replaced the floating **Scroll to bottom** pill with a small down arrow below the composer. It stays available when you scroll back without covering the conversation.

## Antigravity

- If Antigravity cannot restore a conversation, Harness keeps the saved session and reports that the message was not sent. It no longer sends a follow-up into an empty replacement session.
