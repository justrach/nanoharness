# NanoHarness v0.2.219

## Interactive commands in desktop chat

- On macOS and Linux, supported shell blocks in completed assistant replies now show a terminal button by default in local chats. Review the command and its working directory, then choose **Run in terminal** to start it.
- Answer prompts in the terminal dock without sending input to chat. Click the block’s terminal button again to reopen the same session without rerunning the command.

## Engine and sync

- Reopening a remote chat catches up missing messages. Cold chat switches fetch the newest transcript rows first, and workspace discovery bounds scans of the home directory (#80).
- Idle time no longer counts toward the self-continue time limit, and ACP tools left open are shown as background tasks (#81).
