# NanoHarness v0.2.226

## Desktop workspace

- Horizontal splits keep pane headers aligned with their panes in a dedicated row. Workspace tabs and window controls stay in the titlebar.
- Cloud sandbox controls move into the titlebar when the sidebar is closed, so they no longer cover pane titles. The side panel toggle only appears when the panel is open or has something to return to, and the New tab button no longer shows a floating hover label.

## Local usage

- Settings → Usage now breaks down tokens by model, labels the runtimes, formats date ranges, and offers expandable input and output totals.
- Local usage scans now skip oversized or malformed records and continue reading. Antigravity attribution uses model metadata when available and preserves unattributed totals when the model cannot be determined.
