# NanoHarness v0.2.222

## Desktop

- The macOS updater checks which version is installed before offering a restart. If the installer reports that the update is already installed, Harness recognizes the matching on-disk bundle instead of offering the same update again. A mismatched or withdrawn update is not marked ready.
- Narrow chat panes show readable tool summaries and filenames. The full summary is available on hover; open a tool row to see its details.
- Resolved questions no longer leave a chip in the transcript. Unanswered questions remain visible and actionable.

This release retains the v0.2.221 Antigravity follow-up recovery and the composer’s unobtrusive jump-to-bottom control.
