# NanoHarness v0.2.239

## Typed slash commands

- Send a draft that is just a slash command, such as `/compact`, as the agent's command rather than as plain text. Before, it reached the agent as an ordinary prompt when Return was pressed before the command list had loaded, when it was sent with Cmd+Return or the Send button, or after command discovery failed; graff then answered it instead of running it. A send while the command list is still loading now waits for it, and failed discovery stops the send once with a notice before sending it as typed. Commands with arguments still need the completion menu (#205).
