# NanoHarness v0.2.238

## Signed update manifests

- Sign published `manifest.json` release manifests with Ed25519 (`RELEASE_MANIFEST_SIGNING_KEY`, failing closed if unset), embed the production `release_verify_key` in NanoHarness, and align `scripts/gen-release-key.py` (with an OpenSSL 3 fallback and round-trip tests) to `updates_host.zig::manifestMessage` (#195).

## Windows rendering and window chrome

- Bring Windows D3D11, DirectWrite, and DXGI rendering to SDR parity with Metal by selectively porting `nanoui` `v0.14.11` improvements: continuous and circular `corner_sdf_aa`, 8-sample dithered shadows, multi-stop `gradient_stops`, GDI Classic per-analysis glyph blending and whole-pixel grid advances, circular rounded-clip preservation across renderers, and explicit sRGB swap-chain color space configuration (#195).
- Draw Windows caption **Minimize**, **Maximize**, and **Restore** buttons as transparent `12x12` `ui.canvas` vector strokes matching **Close**, eliminating the opaque `k.shell` cutout inside hovered Maximize and Restore icons (#195).
